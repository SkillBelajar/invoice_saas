# Memori Proyek — SaaS Invoicing & Piutang

**Versi Aplikasi:** 0.4
**Status:** Slice 1 — Setup Infrastruktur Dasar & File Memori (Selesai)

---

## 1. Ringkasan 5W+1H

| | |
|---|---|
| **What** | Aplikasi SaaS Invoicing & manajemen piutang untuk transaksi B2B dan B2C. Membuat invoice, mengirim ke klien, memantau status pembayaran, dan mengelola aging piutang. |
| **Who** | Owner dan Admin Usaha (UMKM, jasa, dagang, vendor B2B). Bukan untuk akuntan profesional — bahasa awam, alur pendek. |
| **Why** | Usaha kecil menagih lewat WhatsApp dan catatan manual; invoice hilang, jatuh tempo terlewat, piutang tak terlacak. Aplikasi ini menyatukan penerbitan invoice, penomoran rapi, dan pemantauan piutang dalam satu tempat. |
| **Where** | Aplikasi web (browser desktop & mobile), multi-tenant per usaha, di-deploy sebagai container Docker di VPS. |
| **When** | Dipakai harian saat menerbitkan invoice, dan mingguan saat menagih piutang jatuh tempo. |
| **How** | Laravel 13 + Octane (FrankenPHP/Swoole) sebagai backend API & rendering, Inertia.js + Vue 3 untuk UI reaktif tanpa API terpisah, MySQL untuk data, Redis untuk cache/queue/session, Nginx sebagai reverse proxy. |

### Kepatuhan & Standar

- **UU HPP (Harmonisasi Peraturan Perpajakan)** — struktur pajak invoice mendukung PPN dan pencantuman DPP/nilai pajak terpisah; PPh tidak dihitung aplikasi, hanya dicatat sebagai referensi.
- **SAK EMKM** — laporan dan istilah mengikuti Standar Akuntansi Keuangan Entitas Mikro, Kecil, dan Menengah: pendapatan, piutang usaha, dan jatuh tempo sederhana tanpa jurnal berpasangan penuh.
- Nominal uang disimpan sebagai integer desimal (bukan float); pembulatan ditampilkan, bukan disimpan.

## 5. Jebakan Teknis yang Sudah Diketahui

- **Host CPU tanpa AVX2 (Intel i5-3470).** Vite 8 (rolldown) crash `Illegal instruction (core dumped)` — SIGILL 132. Wajib pin `vite@^7` + `laravel-vite-plugin@^2`. Plugin v3 mensyaratkan vite ^8, dan vite 7 tidak punya export `laravel-vite-plugin/fonts` — font Bunny dihapus dari `vite.config.js`.
- **Bind mount menutupi `vendor/` hasil build image.** Entrypoint menjalankan `composer install` bila `vendor/` kosong. Di mesin dev, `vendor/` host yang dipakai.
- **`env_file` dibaca saat container dibuat.** Mengubah `.env` lalu `docker compose restart` tidak berefek. Harus `docker compose up -d --force-recreate <service>`.
- **Nginx cache IP upstream.** Setelah `app` di-recreate, request bisa 502 walau `app` healthy — `docker restart web` memperbaiki.
- **Config cache menahan nilai lama.** Mengubah `.env` lalu `config:clear` saja tidak cukup bila worker Octane sudah memegang nilai; perlu `octane:reload` atau recreate container.
- **Cloudflare Tunnel + Laravel = mixed content.** Tunnel memutus TLS dan meneruskan HTTP polos ke Nginx, jadi Laravel mengira request-nya `http://`. Akibatnya asset dan redirect Inertia XHR diarahkan ke `http://`, diblokir browser. Wajib: `$middleware->trustProxies(at: '*')` di `bootstrap/app.php` **dan** `URL::forceScheme('https')` di `AppServiceProvider::boot()` ketika `X-Forwarded-Proto: https`. Fallback port di `docker/nginx/default.conf` harus `443`, bukan port lokal — kalau tidak, `X-Forwarded-Port` membocorkan `:8181` ke URL publik.
- **Port host bertabrakan dengan stack lain di mesin ini.** 8080 (ljk_web), 8090 (siakad_web), 33061 (ljk_db), 63791 (ljk_redis). Karena itu proyek ini memakai 8181 / 33071 / 63801.
